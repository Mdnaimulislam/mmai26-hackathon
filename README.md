# Clinical Strand — Can You Trust an AI in the ICU?

**MultimodalAI'26 Hackathon · 10 June 2026**

**Challenge:** Three AI models predict which ICU patients will deteriorate
in the next 24 hours. Your team produces the evidence to decide which ones
should be trusted — and which ones should not.

> Read **[STRAND_GUIDE.md](STRAND_GUIDE.md)** first if you are new to clinical AI evaluation,
> ICU data, or multi-person hackathon workflows.

---

## Quick start

```bash
pip install -r requirements.txt

# Step 1 — open the training notebook
jupyter notebook notebooks/01_explore_and_train.ipynb
# (or open in Google Colab — no installation needed)

# Step 2 — implement your model (B or C) in models/
# Open models/model_b.py  OR  models/model_c.py  and follow the design brief

# Step 3 — implement the evaluation functions in src/evaluate.py

# Step 4 — once models are saved, launch the app
streamlit run app.py
```

---

## What you build

| File you work in | What you implement |
|---|---|
| `models/model_b.py` | Vitals-only model — your architecture, your design choices |
| `models/model_c.py` | Notes-dependent model — your missing-data strategy |
| `src/evaluate.py` | Classification metrics, subgroup analysis, calibration |
| `src/report.py` | Add custom metrics to METRIC_REGISTRY (optional) |
| `app.py` | Already complete — uses whatever your evaluate.py returns |

## Final deliverables  (in `reference/`)

| File | What it is |
|---|---|
| `Model_Safety_Report.html` | Safety report with APPROVE / CONDITIONAL / NOT APPROVED per model |
| `evaluation_metrics.csv` | All computed metrics in a flat CSV |
| `omaib_submission.json` | OMAIB-compatible model card (schema: omaib-clinical-v0.3) |

All three are generated by clicking buttons in the Report Builder tab of the app.

---

## Judging criteria

| Criterion | What judges look for |
|---|---|
| **Evidence quality** | Are findings quantified and specific? Did the team find real failure modes? |
| **Clarity** | Could a clinical governance team read the safety report and act on it? |
| **Deployability** | Is the OMAIB JSON clean and complete? Does the verdict match the evidence? |

## Directory structure

```
clinical_strand/
  data/

  saved_models/                 created by notebook (.joblib files)
  saved_metrics/                created by notebook (training_metrics.csv)
  src/
    evaluate.py                 IMPLEMENT — metrics, subgroup analysis, calibration
    report.py                   PROVIDED — dynamic HTML + OMAIB JSON generation
  reference/                    FINAL OUTPUTS — judges look here
  app.py                        PROVIDED — Streamlit evaluation and reporting app
  STRAND_GUIDE.md               Cross-domain participant guide
  requirements.txt
```
