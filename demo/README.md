# Housing Strand Demo Starter

This `demo/` package is a guided, lightweight walkthrough for the housing strand.
It is designed for participants to:

- run an end-to-end baseline pipeline on a small data subset,
- train 3 lightweight models,
- inspect evidence required by `STRAND_GUIDE.md`,
- and provide a guided workbench for participants to complete deliverables themselves.

## Folder structure

- `data/raw/`: small subset split into modalities.
- `data/processed/`: intermediate artifacts generated by notebooks or scripts.
- `notebooks/`: runnable step-by-step demo notebooks.
- `models/`: optional placeholder folder for participant custom model files.
- `src/`: reusable Python modules (loading, training, evaluation, reporting).
- `reference/`: demo copies of required submission schemas.
- `saved_metrics/`: exported metrics CSV files.
- `saved_models/`: serialized model files.
- `requirements.txt`: minimal dependencies for demo execution.
- `app.py`: simple script entrypoint for the baseline flow.

## Quick start

From repository root:

```bash
pip install -r demo/requirements.txt
python -m streamlit run demo/streamlit_app.py
```

Alternative CLI run:

```bash
python demo/app.py
```

Guided notebook run order:

1. `demo/notebooks/01_data_explore.ipynb`
2. `demo/notebooks/02_preprocess_and_split.ipynb`
3. `demo/notebooks/03_train_models.ipynb`
4. `demo/notebooks/04_evidence_dashboard.ipynb`

## Important notes

- This demo uses a subset of the housing dataset for speed.
- The full challenge requirements are in repository root:
  - `README.md`
  - `STRAND_GUIDE.md`
- Participants should expand this baseline to satisfy full strand deliverables.
- `data/processed/`, `saved_metrics/`, and `saved_models/` are starter-empty and populated when participants run notebooks/app.
- The starter kit does **not** produce final deliverables automatically.
- Teams must manually complete `reference/omaib_pathway.json` and `reference/housing_benchmark_card.json` (in the repo's `reference/` folder).
